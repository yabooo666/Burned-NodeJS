## 1. Quick Project Summary

**Burned NodeJS** is a high-performance, single-file server monitoring agent and PM2 process dashboard for Linux VDS/VPS instances. It is engineered with:
- **Zero external runtime dependencies** (uses Node.js 18+ built-ins: `node:http`, `node:sqlite`, `node:crypto`, `node:fs`, `node:child_process`).
- **Single-file deployment artifact**: The compiled Vue 3 Single-Page App (SPA) is embedded directly into the Node.js agent script, bundled by `esbuild` into one standalone file (`dist/burned-agent.js`, ~1.2 MB).
- **Native SQLite Authentication**: Passwords hashed with `node:crypto` `scrypt`, verified with `timingSafeEqual`, active session tokens stored in local `burned.db`.
- **Hardened Zero-Shell PM2 Controls**: Process management commands (`start`, `restart`, `stop`, `reload`) are executed strictly via `node:child_process.execFile` with **zero shell spawning**, strict action whitelisting, and target validation against verified numeric process IDs. Arbitrary command execution and shell interpolation remain strictly prohibited.
- **OLED Black Monochrome Aesthetic**: `#000000` pitch black, high-contrast grays, sharp SVGs, **ABSOLUTELY ZERO EMOJIS** in the interface, and responsive Pterodactyl-inspired process switcher tabs.

## 3. Core Architectural Principles

### 3.1 Single-File Embedding Pipeline
```
[src/ui/ (Vue 3 + CSS)]
         │ (npm run build:ui)
         ▼
[vite-plugin-singlefile] ──> Produces 1 inline file: dist-ui/index.html (HTML + CSS + JS)
                                        │
                                        ▼ (node build.agent.js)
                             [src/agent/embedded-ui.ts] (export const EMBEDDED_HTML = `...`)
                                        │
                                        ▼ (esbuild --bundle --platform=node)
                             [dist/burned-agent.js] (~1.2 MB)
```
- The production output `dist/burned-agent.js` can be copied to **any** Linux machine running Node.js 18+ and executed directly with `node dist/burned-agent.js` or `pm2 start dist/burned-agent.js`.
- When an HTTP request arrives for `/`, the server responds with `EMBEDDED_HTML` with headers `Content-Type: text/html; charset=utf-8`.

### 3.2 Network Binding & Environment Defaults
- **Default Port**: `27109` (configured via `process.env.PORT || '27109'`).
- **Default Host**: `127.0.0.1` (configured via `process.env.HOST || '127.0.0.1'`).
- **Automatic `.env` loader**: `src/agent/index.ts` natively reads `.env` from the current working directory without external npm dependencies (`dotenv` is NOT used).
- **Public Binding**: If the user wants the dashboard accessible over public IP / LAN, they set `HOST=0.0.0.0`.
- **PM2 Gotcha**: PM2 caches environment variables. Any environment variable changes (`.env` or CLI) require `--update-env` when restarting:
  ```bash
  pm2 restart burned-agent --update-env
  ```
